## 使用流程
1. 先輸入**保險年齡**（或用生日換算：足歲，零數超過 6 個月加 1 歲）、**性別**、**職業類別**。
2. 系統依各商品**投保規則**自動篩出「此年齡可投保」商品，依類別分組；不可投保的收在下方並列出年齡區間。
3. 點商品 → 選年期（只出現此年齡可選的）、保額（顯示此年齡／職業的上下限）、繳別、繳費方式折扣 → 立即算出保費。
4. 不合規則（年齡、年期、保額上下限、級距）會直接擋下並說明原因。
5. 「加入組合」可累加多張主約，並一鍵複製文字貼 LINE。

## 資料來源與計算方式
- **費率**：只取自各商品「建議書試算 Excel」的 GP 費率表（`build/rates_raw.json`），並**逐格比對 PDF 費率表**：收錄範圍 5,486 格中 5,485 格吻合，唯一例外見下方限制（`build/pdfcheck.py`）。不自行推估費率。
- **投保年齡／年期／保額上下限**：取自各商品最新版投保規則（114.02.21 後版本等）。
- **折扣**：取自保費規定。繳費方式 1%（首期匯款／轉帳／富邦信用卡；續期轉帳／富邦信用卡／自行繳費）；HJI 日額 ≥1,000 元另享高保額 2%（合計上限 3%）；HSZ、LTV 躉繳沒有折扣。
- **公式（對齊建議書 OP 頁）**：年繳＝ROUND(保額單位數×費率,1)；繳別保費＝ROUND(年繳×繳別係數,0)；實繳＝ROUND(繳別保費×(1−折扣),0)。繳別係數：半年 0.52、季 0.262、月 0.088；HIY1 依其建議書用「直接除」（0.5／0.25／1/12）。
- 重建資料：`cd build && python3 extract2.py && python3 extract3.py && python3 extract4.py && python3 extract5.py && python3 build.py`（商品設定寫在 `build/build.py` 的 `P` 清單）。

## 限制（請務必注意）
- **以公司正式建議書、保單條款及核保結果為準**；本工具只供內部快速試算。
- 只做核保規則中的年齡、年期、單一商品保額上下限檢查。**跨商品累計限額**（例如醫療日額累計 8,000／同業 15,000、長照通算 100 倍）、體檢額度、職業不保、財務核保都**沒有**檢查。
- 健康管理保險費折扣（續期才適用）只用文字提醒，沒有算進金額。員工件、集彙件折扣不計。
- HJL 為一年期自然費率：只顯示首年保費。
- 給付只列出給付項目名稱，金額倍數請看條款／商品內容說明；HAC/HAD 各計劃的給付額度表還沒放進來。
- 已知資料差異：LTP 20 年期、男 59 歲，建議書 Excel 費率 440，PDF 費率表 445（畫面會跳警示）。（HIZ 的 Excel 有 0–15 歲費率，但現行投保規則與 PDF 都是 16–70 歲，已依規則擋掉。）
- HIY1 職業第 6 類的最低保額寫法不明確；目前設定 16–55 歲 800 元、56–60 歲 500 元。
- 保險年齡以「今天」換算；實際以要保書申請日為準。
